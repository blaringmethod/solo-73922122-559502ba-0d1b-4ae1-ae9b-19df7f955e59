疾控汇总发布安全审查台（内部）

查看公开页 →

1. 导入调查数据

CSV 表头：分区,年龄组,人数,检出数。至多 16 格；人数 ≥ 5；检出数为 0~人数的整数；（分区,年龄组）组合唯一。导入后不可更换。

2. 原始数据（仅内部可见，公开页不含格内检出数）

3. 选择发布范围并预览 / 发布

4. 已公开记录（不可撤销）

5. 报送补正 / 作废对账

CSV 表头：报送ID,修订号,分区,年龄组,人数,检出数,作废标记。修订号为正整数； 有效记录须满足 0 ≤ 检出数 ≤ 人数；作废标记可用 是/否、1/0、true/false（留空视为否）。 同一报送ID 只以最高修订贡献汇总；更高修订到达后旧版不再计入（迟到旧版也不会复活）。 同 ID 同修订内容相同的重传不重复计数；内容冲突或任一行非法则整批拒收，旧结果不变。
